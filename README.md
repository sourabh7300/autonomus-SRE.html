# 🧪 The Lab — monorepo of single-file apps

> One repo, a whole portfolio of experiments: SRE, DevOps, AI assistants and utility tools — each a self-contained HTML app.

**🔴 Live demo:** https://sourabh7300.github.io/autonomus-SRE.html/

## What it does
- **autonomous-sre.html** — multi-agent incident responder: detection → triage → remediation, visualized
- **cloudpilot.html** — CloudPilot: infrastructure that ships itself (IaC console)
- **kin_copilot_standalone.html** — Kin, the copilot that remembers (bring your own key)
- **jarvis_1.html** — J.A.R.V.I.S Mark VII dev console & AI neural link
- **voice_assistant.html** — Echo: ask anything, answers out loud
- **devops-math.html** — the numbers behind the pipeline
- **task-tracker-web.html** — CloudNative task tracker
- **sourabh-ai.html**, **api-key-manager.html**, **llmops-pipeline.html**, **pipeline-dashboard.html**, **shieldlink.html**, **url-snip.html**, **forge.html**, **sky-ledger-weather.html**, **ephemeral-playgrounds.html** — and more
- Every file is standalone: download one, double-click, it works.

## Built with
HTML · CSS · JavaScript — **zero frameworks**, single file, runs in any browser.
